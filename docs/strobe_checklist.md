# STROBE checklist (cross-sectional studies)

Item numbers follow the STROBE statement (von Elm et al., Lancet 2007). Locations refer to sections of `output/report/manuscript.docx`, built from `manuscript/manuscript.md`.

| Item | Recommendation | Location |
|---|---|---|
| 1a | Indicate the study design in the title or abstract | Title; Abstract, Methods ("cross-sectional analysis") |
| 1b | Informative and balanced abstract | Abstract |
| 2 | Scientific background and rationale | Introduction, paragraphs 1-2 |
| 3 | Objectives, including prespecified hypotheses | Introduction, paragraph 3 |
| 4 | Key elements of study design | Methods, Data source and population |
| 5 | Setting, locations, dates of recruitment and data collection | Methods, Data source and population (CCHS 2017-2018, household population of Canada) |
| 6a | Eligibility criteria and selection of participants | Methods, Data source and population; supplementary flow diagram |
| 7 | Define outcomes, exposures, confounders and effect modifiers | Methods, Measures; supplementary data dictionary |
| 8 | Data sources and measurement for each variable | Methods, Measures; data dictionary |
| 9 | Efforts to address sources of bias | Methods, Measures (BMI bias adjustment); Missing data; Statistical analysis (sensitivity analyses) |
| 10 | Study size | Methods, Data source and population; flow diagram |
| 11 | Handling of quantitative variables | Methods, Measures (categories and cut-points) |
| 12a | Statistical methods, including control for confounding | Methods, Statistical analysis |
| 12b | Methods for subgroups and interactions | Methods, Statistical analysis (multiplicative and additive interaction; age groups) |
| 12c | How missing data were addressed | Methods, Missing data |
| 12d | Sampling strategy taken into account | Methods, Statistical analysis (survey weights, bootstrap replicate weights) |
| 12e | Sensitivity analyses | Methods, Statistical analysis; Results, Sensitivity analyses; Table S2 |
| 13a | Numbers of individuals at each stage | Methods; supplementary flow diagram |
| 13b | Reasons for non-participation at each stage | Flow diagram (exclusions and missing data) |
| 13c | Flow diagram | `output/figures/flow_diagram.png` |
| 14a | Characteristics of participants | Results; Table 1 |
| 14b | Number of participants with missing data for each variable | Table 1 (missing rows); `output/tables/missing_by_variable.csv` |
| 15 | Numbers of outcome events or summary measures | Results, paragraph 1; Table 1; `output/tables/prevalence.html` |
| 16a | Unadjusted and adjusted estimates with precision; confounders adjusted for | Results; Tables 2 and 3; `output/tables/table3.html` |
| 16b | Category boundaries for categorized continuous variables | Methods, Measures |
| 16c | Translation of relative risk into absolute risk where relevant | Results, Additive scale (standardized prevalence differences); Table 3 |
| 17 | Other analyses: subgroups, interactions, sensitivity analyses | Results, Age groups and Sensitivity analyses; Figure 2; Tables S1-S3 |
| 18 | Key results with reference to objectives | Discussion, paragraph 1 |
| 19 | Limitations, including sources of bias and imprecision | Discussion, limitations paragraph |
| 20 | Cautious overall interpretation | Discussion; Conclusion |
| 21 | Generalisability | Discussion (household population; pre-pandemic data) |
